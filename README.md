# AK's Expense Tracker

Free static web app for GitHub Pages + Supabase.

1. Create a Supabase project.
2. Run schema.sql in Supabase SQL Editor.
3. Copy config.example.js to config.js.
4. Put your Supabase Project URL and browser-safe anon/publishable key in config.js.
5. Upload index.html, config.js, schema.sql and README.md to GitHub.
6. Enable GitHub Pages from Settings > Pages > Deploy from branch > main > root.

Never put a Supabase service_role/secret key in config.js.
